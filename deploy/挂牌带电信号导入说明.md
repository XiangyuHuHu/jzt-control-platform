# 挂牌/带电信号导入说明（设备新0601）

本说明用于把 `洗煤厂设备新0601.csv` 中的 **挂牌、带电** 两类信号，统一导入平台 `iot_tag` 和 `iot_tag_mapping`。

## 1. 本次统一规则

- 仅导入 `Tag Name` 末尾为：
  - `.带电`
  - `.挂牌`
- `tagname` 组成：`设备名称.状态`
  - 示例：`111AZ制动电机.带电`
  - 设备名：`111AZ制动电机`
  - 状态：`带电`
- `source_path` 固定格式：

```text
NS2|String|洗煤厂PLC.洗煤厂设备新.<tagname>
```

示例：

```text
NS2|String|洗煤厂PLC.洗煤厂设备新.111AZ制动电机.带电
NS2|String|洗煤厂PLC.洗煤厂设备新.111AZ制动电机.挂牌
```

## 4. 导入后核查

```sql
-- 导入数量（仅挂牌/带电）
SELECT COUNT(*) FROM iot_tag
WHERE tag_name LIKE '%.带电' OR tag_name LIKE '%.挂牌';

SELECT COUNT(*) FROM iot_tag_mapping
WHERE business_name LIKE '%-带电' OR business_name LIKE '%-挂牌';

-- 抽样核查 source_path
SELECT tag_code, tag_name, source_path
FROM iot_tag
WHERE tag_name LIKE '111AZ制动电机.%'
ORDER BY tag_name;
```
